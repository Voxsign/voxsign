# VoxSign

Voice assistant platform: a SwiftUI iOS client paired with a zero-dependency Go voice command engine.

## Repositories

| Repository | Description | Visibility |
|---|---|---|
| [VoxSign-IOS](https://github.com/Voxsign/VoxSign-IOS) | iOS client (SwiftUI). English-first UI with Simplified Chinese localization | Public |
| [VoxSignHarness](https://github.com/Voxsign/VoxSignHarness) | Server-side voice command engine (Go, standard library only) | Public |
| VoxSign-Server | Server deployment and internal design documents | Private |
