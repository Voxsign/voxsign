# Contributing to VoxSign

This repository is the VoxSign organization landing page. The code lives in
two repositories:

- **VoxSign-IOS** — the iOS client
  (https://github.com/Voxsign/VoxSign-IOS)
- **VoxSignHarness** — the server-side voice harness
  (https://github.com/Voxsign/VoxSignHarness)

To contribute code, open a Pull Request in the relevant repository and follow
its CONTRIBUTING.md (fork → feature branch → signed commits → PR → CI green →
maintainer review).
