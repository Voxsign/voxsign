# Model Center · 自愈与自动下线设计

> 状态：设计稿（2026-10）。运行核查结论见文末；实现状态需服务器侧核实。

## 1. 目标

让模型中心在**无人干预**的情况下保持对外可用：

- 任何模型不可用 / 欠费 / 异常 → 自动兜底，请求最终有结果；
- 质量不达标的模型 → 自动降级、切换、下线并告警；
- 每次异常都有日志、有动作、有验证、有记录，形成自愈闭环。

## 2. 监控指标（自愈判定的输入）

| 指标 | 阈值示例 | 判定 |
|---|---|---|
| 在线状态 | 连续 N 次探测失败 | 模型不可用 |
| 调用成功率 | 5 分钟内 < 95% | 质量异常 |
| 延迟 P95 | > 阈值（如 10s）且持续 | 性能劣化 |
| 错误分布 | auth / budget / network 类错误激增 | 分类处理 |
| 余额 / 预算 | 余额 < 阈值 或 日预算耗尽 | 欠费预警/停机 |
| 模型版本 | 发布 > 6 个月且无更新 | 过时候选 |
| 上下文/能力不匹配 | 同一任务反复失败 | 路由不当 |

## 3. 自愈动作集（按序触发）

```
探测异常 → 自动重试(≤2轮, 可修正参数) → 切换备选模型(同池) → 
降级路径(低配模型/缓存/确定性兜底) → 标记不可用 → 告警+通知
```

- **重试**：瞬时错误（transient）自动重试，最多 2 轮；
- **切换**：模型不可用 / 鉴权失败 / 欠费 → 切同池备选（预算与质量最优者）；
- **降级**：全部备选不可用时走本地确定性兜底（规则/缓存），保证"最终一定有响应"；
- **下线**：连续不达标（成功率、延迟、余额）→ 标记 `unavailable`，从默认路由池移除，仅保留直连入口；
- **告警**：每次自愈动作留痕（日志 + 告警流 + 状态接口可见）。

## 4. 自动下线规则（用户关心的核心）

- **硬下线**：余额为 0 / 欠费 → 立即停止默认路由，仅告警不静默失败；
- **质量下线**：成功率 < 阈值 连续 10 分钟 → 自动下线并通知；
- **延迟下线**：P95 超阈值连续 15 分钟 → 自动降级为备选；
- **过时下线**：发布超 6 个月且测评被新版明显超越 → 移出默认池（保留直连）；
- **恢复**：供应商修复后，探测/测评通过 → 自动重新上线（带灰度）。

## 5. 自愈闭环（每次异常的完整处理链）

```
失败捕获(带轨迹) → 分类(9类: budget/network/param/auth/tool_missing/permission/transient/unknown/quality)
→ 决策(重试/切换/降级/下线/询问) → 执行 → 验证(是否恢复) → 记录(日志+指标+状态)
```

- 决策延迟硬指标：**500ms – 1s**；
- 兜底接口自身故障：自动跳过，不影响原链路；
- 所有动作进入学习接口的训练样本，持续优化路由。
